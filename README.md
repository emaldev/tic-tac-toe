# Tic Tac Toe - Java Swing

A simple Tic Tac Toe game built using Java Swing.

## Features

- 3×3 game board
- Two-player mode (X and O)
- Win detection
  - Rows
  - Columns
  - Diagonals
- Prevents clicking on occupied cells
- Game over detection
- Restart option after a player wins

## Technologies

- Java
- Java Swing

## How to Run

1. Clone the repository

```bash
git clone https://github.com/emaldev/java-swing.git
```

2. Open the project in VS Code or IntelliJ IDEA.

3. Compile and run the project.
